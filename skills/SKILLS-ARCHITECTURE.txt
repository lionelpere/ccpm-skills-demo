## Skill Dependencies

```
Workflow Orchestrator (Independent)
    ├─ Calls → PRD Expert
    ├─ Calls → Epic Planner
    ├─ Calls → Parallel Executor
    ├─ Calls → GitHub Sync
    ├─ Calls → Quality Guardian
    └─ Calls → Developer Guide

PRD Expert (Independent)
    └─ Output used by → Epic Planner

Epic Planner (Depends on PRD)
    ├─ Reads → PRD files
    ├─ Uses → Context Curator data
    └─ Output used by → GitHub Sync

GitHub Sync (Depends on Epic)
    ├─ Reads → Epic + Task files
    └─ Output used by → Parallel Executor

Parallel Executor (Depends on GitHub)
    ├─ Reads → Task files
    ├─ Uses → Context Curator data
    └─ Output validated by → Quality Guardian

Quality Guardian (Depends on Code)
    └─ Reads → PRD + Epic + Task + Code

Context Curator (Independent)
    └─ Used by → All skills

Developer Guide (Independent)
    └─ Helps with → All skills

Legend:
  Independent = Can be used standalone
  Depends on = Requires output from other skill
  Calls = Routes to another skill
  Reads = Consumes files from
  Used by = Provides data to
```

## Package Contents

```
Each .zip contains:
  • SKILL.md (Required)
    - YAML frontmatter
    - Skill instructions
    - Usage examples
  
  • references/ (Optional)
    - Reference documentation
    - Loaded as needed
    - Example: Developer Guide has 4 refs
  
  • assets/ (Optional)
    - Files used in output
    - Not loaded to context
    - Example: Diagram templates

Developer Guide is largest (27KB) because:
  • 4 comprehensive reference files
  • 1 diagram asset file
  • Complete CCPM coverage
  • Troubleshooting database
  • Tutorials and examples
```

## Architecture Principles

```
1. Modular Design
   • Each skill = focused responsibility
   • Skills can be added incrementally
   • No hard dependencies (except data flow)

2. Intelligent Routing
   • Orchestrator detects context
   • Routes to appropriate skill
   • User doesn't need to know which skill

3. Evidence-Based
   • Every claim verified
   • Assumptions flagged
   • No speculation

4. User-Centric
   • Natural language interface
   • Proactive suggestions
   • Always know next step

5. Quality First
   • Spec-driven enforcement
   • Automatic validation
   • Zero scope creep tolerance
```
